# Postwoman для Windows

**Лучше, чем Postman (для простых задач)**

Бесплатное приложение для Windows (на Electron) для работы с коллекциями Postman. Быстрое и лёгкое. Коллекции можно хранить локально или удалённо (например, в синхронизируемой или сетевой папке), с необязательной резервной копией; секретные данные шифруются.

Нативная версия для Mac доступна здесь: https://github.com/silverjohnes/postwoman

**Версия 0.8.5** (сборка 080522)

## Сборка
    npm install
    npm run dist

Готовые файлы появятся в папке `dist`: установщик и portable-версия.

## Основные возможности
- Работа с коллекциями Postman (импорт и экспорт, формат Postman v2.1).
- Поддержка скриптов (pre-request и тесты).
- **Бесплатные массовые запросы**: запуск коллекций и папок с данными из CSV/JSON.
- Переменные ({{var}}); отдельных окружений (environments) нет.
- Шифрование секретных переменных (ключ в учётной записи Windows или локальный ключ).
- Локальное или удалённое хранение коллекций, необязательная резервная копия.
- Интерфейс на 25 языках, несколько цветовых тем.

## Чего нет
Командная работа не поддерживается. Для командной работы используйте Postman.

## Подробное описание функционала

### Коллекции (дерево)
- Папки и запросы: создание, переименование (F2 или Ctrl+E), дублирование (Ctrl+D), удаление, копирование, вырезание и вставка (Ctrl+C / Ctrl+X / Ctrl+V), перетаскивание с зонами «до / внутрь / после», мультивыбор (Shift-клик — диапазон, Ctrl-клик — добавить или убрать), навигация стрелками.
- Если в буфере обмена лежит команда `curl`, вставка (Ctrl+V) в списке создаёт из неё запрос. Импорт из cURL также доступен отдельно (Ctrl+Shift+I), а у запроса есть «Copy as curl».
- Отмена и повтор действий (Undo/Redo) по областям: Ctrl+Z действует в той части, где фокус (список запросов или открытый запрос), Ctrl+Alt+Z и Ctrl+Alt+Shift+Z отменяют и повторяют действие для всего приложения. Удалённое восстанавливается.
- Поиск по имени и по содержимому (URL, заголовки, тело, скрипты); при поиске по содержимому названия не учитываются. Работает с переключением раскладки RU↔EN: запрос «gjbcr» находит «Поиск». Переход по совпадениям: Ctrl+G и Ctrl+Shift+G.
- Черновики (draft) новых запросов, индикатор несохранённых изменений, автосохранение (включено по умолчанию, отключается в настройках), при закрытии программы диалог: сохранить, сохранить все или отбросить.

### Редактор запроса
- Вкладки: Params, Headers, Body, Scripts, History.
- Body: none, form-data (в том числе файлы), x-www-form-urlencoded, raw (JSON, JavaScript, HTML, XML, Text), binary (файл).
- Scripts: Pre-request и Post-request скрипты с подсказками по API `pm.*` (в том числе `pm.test`, `pm.response`, `pm.globals`, `pm.sendRequest`, `pm.visualizer`). В редакторе есть подсветка синтаксиса, поиск (Ctrl+F), комментирование строк (Ctrl+/) и обрамление выделения в `{ }` или `{{ }}` при вводе скобки.
- Автозаголовки (Host, Content-Length, Content-Type, User-Agent `Postwoman/<версия>`, Accept, Accept-Encoding, Connection): их можно переопределить своим значением или отключить. Host и Content-Length обязательные, отключить их нельзя.
- Заголовки на уровне папки наследуются всеми вложенными запросами (только чтение, переопределяются собственным заголовком запроса). При экспорте эти заголовки добавляются в каждый запрос.
- Авторизация при импорте превращается в обычный заголовок или параметр запроса, чтобы значение было видно и его можно было править: bearer, basic, oauth2, apikey. Digest, Hawk, AWS Signature и NTLM остаются на стороне newman. Для basic с переменными в логине или пароле показывается предупреждение.
- В таблицах Params, Headers и form-data ширина колонки «имя» подбирается под самое длинное имя; её можно перетянуть мышью за полоску справа от колонки (запоминается для этого запроса), двойной клик по полоске возвращает автоширину.
- В строке URL: двойной клик выделяет слово, тройной — часть между `/` и `/`, четверной — весь адрес.
- Массовое редактирование: выделите несколько запросов или папку, затем задайте или удалите заголовки, замените тело, укажите Content-Type.
- В строке URL: двойной клик выделяет слово, тройной — часть адреса между двумя `/`, четверной — весь адрес.
- Колонки «название / значение» в таблицах параметров и заголовков меняются перетаскиванием разделителя; по умолчанию ширина подбирается под самое длинное название, вручную заданная запоминается для запроса, двойной клик по разделителю возвращает автоподбор.
- Двойной клик по папке в списке раскрывает или сворачивает её.
- Таймаут запроса задаётся в настройках (в секундах, 0 означает без ограничения).

### Результат запроса
- Вкладки: Request, Response, Visualize, Console (результаты тестов ✔/✘ и `console.log`).
- Показываются код, размер и время ответа. Есть копирование ответа, сохранение тела в файл и «Copy as curl».
- Визуализация (`pm.visualizer.set`) выполняется в изолированном iframe (sandbox без same-origin, библиотека Handlebars вложена в программу). Свежий результат (пришёл меньше 8 секунд назад) открывается на вкладке Visualize, и скрипт отрабатывает сразу. Старый результат открывается на вкладке Response, скрипт запускается только после вашего клика на Visualize.
- Большие тела (больше 4 МБ) обрезаются при записи в историю, отображение виртуализовано, поэтому гигантские ответы не подвешивают окно.
- Кнопка Beautify форматирует JSON; в поле тела запроса подсветка строится только для видимых строк, поэтому несколько мегабайт JSON вставляются и форматируются быстро.

### Раннер
- Запуск коллекции, папки или одного запроса. Итерации от 1 до 100000, интервал между запросами от 0 до 3600000 мс, файлы данных CSV и JSON (одна строка данных на итерацию), предпросмотр данных и подстановки переменных.
- Errors CSV: строки данных, на которых запрос упал (без дубликатов).
- Pause (Ctrl+Shift+P), Resume и Stop (Ctrl+.). Каждый запрос выполняется отдельным запуском newman, поэтому управление точное, а Stop прерывает и текущий запрос.
- Подстановка `{{var}}` без учёта регистра. Значения, записанные скриптами (`pm.globals.set`), возвращаются в список переменных (секретные остаются зашифрованными).

### Переменные и секреты
- Вкладка «Переменные»: список переменных, включение и отключение, пометка «замком» для секретных.
- Секретные переменные хранятся в виде `pwenc:1:<iv>.<tag>.<ct>` (AES-256-GCM, случайный ключ данных).
- Два режима хранения ключа: обёрнутым средствами учётной записи Windows (DPAPI, файл `secret.key`) или в локальном файле (`secret.local.key`, не переносится вместе с данными на другой компьютер). Если встроенное шифрование недоступно, программа предлагает локальное и предупреждает об ограничении. Режимы переключаются в настройках с перешифровкой всех значений и обработкой тех, что не удалось расшифровать.
- Доступ к расшифровке защищён Windows Hello (PIN, отпечаток, лицо) через UserConsentVerifier. Запрашивается один раз за сеанс; если попытка не удалась, программа больше не спрашивает, пока вы не сбросите это в настройках. Кнопка «Lock now» блокирует доступ немедленно.
- Секретные значения не попадают в экспорт коллекции и не пишутся в журнал.

### Импорт и экспорт
- Импорт коллекции Postman (v2.0 и v2.1) и команд cURL; экспорт в чистый формат Postman v2.1 (заголовки папок добавляются в запросы, секретные переменные исключаются).

### Хранение и история
- Данные лежат в `collection.json`, `globals.json` и `history/<id запроса>.json`. Путь хранения задаётся в настройках (в том числе сетевая или синхронизируемая папка) плюс необязательная резервная папка: запись идёт в обе, чтение с резервной при недоступности основной. Недоступные пути помечаются, есть кнопка проверки.
- История выполнений по каждому запросу с деталями, мультивыбором и удалением. Автоочистка по сроку (по умолчанию 6 месяцев, можно задать в днях или месяцах).
- Вкладка Log: журнал работы программы с выбором уровня детализации.

### Интерфейс
- Меню и заголовок окна оформлены в цвет программы. Четыре цветовые темы (светлая, тёмная, midnight, sepia) переключаются кнопкой-лампочкой в заголовке, в меню «Окно» и в настройках.
- Интерфейс на 25 языках (язык задаётся автоматически или в настройках).
- Горячие клавиши: окно по F1 (или Ctrl+P для настроек). Вкладки переключаются Ctrl+1…4 (запрос, раннер, переменные, журнал).
- Настройка «Reverse scroll direction» меняет направление прокрутки колесом и тачпадом (по умолчанию выключена).
- Установщик (NSIS) с выбором «для всех пользователей или для текущего», определением установленной версии с предложением обновить или удалить, а также portable-версия без установки.
